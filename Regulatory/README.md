# Bedsore Monitoring & Prevention System  

This repository contains **regulatory documentation samples** and **technical files** for a TRL-4 prototype developed at IIT Guwahati.  
The project focuses on preventing **pressure ulcers (bedsores)** through continuous monitoring of high-pressure regions.  

## Project Highlights
- Electronics and PCB designed using **KiCAD & Fusion 360**.  
- Firmware implemented on microcontrollers with real-time monitoring and alerts.  
- Documentation aligned with **FDA Class II**, **EU MDR Class IIa**, and **CDSCO monitoring device** pathways.  

## Repository Structure
- `Technical_Dossier.md` – Device description, intended use, and regulatory pathway mapping.  
- `Usability_Engineering_Report.md` – Human factors engineering analysis.  
- `Risk_Management_File_ISO14971.md` – Hazard identification and control measures.  
- `Verification_Validation_Plan.md` – Verification and validation framework for sensors and alarms.  

## Disclaimer
These documents are **mock regulatory files** created for academic demonstration and are not official submissions.
