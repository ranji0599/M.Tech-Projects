# Technical Dossier – Bedsore Monitoring System  

## Device Description  
Wearable system for continuous monitoring of pressure points to prevent bedsores.  

## Design Overview  
- Sensors integrated into mattress overlay.  
- Electronics & firmware for real-time data logging and alerting.  

## Regulatory Pathways  
- US FDA: Class II (pressure ulcer prevention device).  
- EU MDR: Class IIa.  
- CDSCO: Medical Device (monitoring category).
